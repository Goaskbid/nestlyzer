# District boundaries used for City zones

| City | File | Origin | Licence |
|---|---|---|---|
| Paris | paris.geojson | Ville de Paris open data "Arrondissements" (fields c_ar, c_arinsee), via github.com/martinfleis/sds | ODbL 1.0 (Ville de Paris) |
| Berlin | berlin.geojson | Amt für Statistik Berlin-Brandenburg district geometries, via github.com/funkeinteraktiv/Berlin-Geodaten (README states CC-BY) | CC BY |
| Vienna | vienna.geojson | Stadt Wien district boundaries from data.gv.at, via github.com/codeforgermany/click_that_hood | CC BY 4.0 (Stadt Wien) |
| Barcelona | barcelona.geojson | Ajuntament de Barcelona CartoBCN "Unitats administratives" shapefile (field DISTRICTE), via the mirror github.com/martgnz/bcn-shp-zip, reprojected from ETRS89 UTM 31N | CC BY 4.0 (Ajuntament de Barcelona) |
| Budapest | budapest.geojson | OpenStreetMap administrative boundaries, via github.com/ANETILab/public_transport_in_the_15minute_city | ODbL 1.0 (© OpenStreetMap contributors) |

Coordinates rounded to 4 decimals and thinned to about 25 m. Joined to the delivered statistics by official district number or code only.
