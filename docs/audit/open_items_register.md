## Rules for these items

- No scoring change from a status update: missing stays missing (no zeros, no perfect quiet or nature scores for absent coverage), regional or estimated values are never relabelled as municipal measurements, weights unchanged.
- Cluster semantics carried forward from the source register (not re-verified here): French establishments and employee positions are separate measures; Dutch establishments are not jobs; Eurostat regional employment is not municipal and not a measured 15 km catchment.
- Close a data gap only with the original payload: bytes and checksum, schema, units, periods, exact geographic identifiers, reuse evidence, source reconciliation, mapped and held row counts. Scoring approval stays a separate step.
- Close a coat-of-arms gap only with the exact municipality and vintage, image bytes, file-specific licence, author and revision, checksum, symbol-use review, and automatic rendering. A placeholder, file name or national flag does not count. Already approved arms stay.
